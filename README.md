### [Zeno](https://github.com/chmenegatti/zeno)

Cliente de API desktop **sem abas**: uma tela, coleções em YAML versionáveis no git e segredos criptografados com a chave no chaveiro do sistema.

- 📁 Cada request é um arquivo YAML
- 🔐 Cofre de segredos local
- 📥 Importa coleções do Insomnia
- 🖥️ Linux · Windows · macOS, sem conta nem telemetria
- ⚙️ Go + Wails
